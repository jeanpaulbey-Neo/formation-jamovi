# Formation Statistiques avec Jamovi — application web (PWA)

Application de formation interactive basée sur le manuel « Apprentissage des
statistiques avec Jamovi » (Navarro & Foxcroft, trad. J.-M. Meunier, CC BY-SA 4.0) :
15 chapitres, 125 questions de quiz corrigées, exercices pratiques et glossaire.

## Mise en ligne sur GitHub Pages

1. Créez un compte sur github.com (gratuit) si besoin.
2. Créez un dépôt public, par exemple `formation-jamovi`.
3. Téléversez TOUS les fichiers de ce dossier à la racine du dépôt
   (index.html, manifest.webmanifest, sw.js, les 3 icônes).
4. Dans le dépôt : Settings → Pages → Source : « Deploy from a branch »,
   branche `main`, dossier `/ (root)` → Save.
5. Après 1 à 2 minutes, l'app est en ligne sur
   `https://VOTRE-PSEUDO.github.io/formation-jamovi/`

## Installation comme application

Ouvrez l'URL dans Chrome ou Opera : une icône d'installation apparaît à droite
de la barre d'adresse (« Installer l'application »). L'app s'ouvre alors dans sa
propre fenêtre, avec icône dans le menu Démarrer/dock, et fonctionne hors-ligne.
La progression est enregistrée automatiquement dans le navigateur.
